# Persistent Memory

- `zh`: 用于跨对话保存用户或项目级偏好、长期约束和已确认的工程决策。
- `en`: Use for persistent memory that stores user or project preferences, durable constraints, and confirmed engineering decisions across conversations.
- Do not store temporary draft parameters, transient calculations, secrets, or values that only apply to the current turn.
- Prefer project scope when the memory belongs to the active engineering project; prefer user scope for stable personal preferences.
